🏟️ Mural de Partidas da Arena (Banco Local / Quarkus)

Partidas registradas na API Quarkus (GET /partidas). Envie seu palpite (POST /palpites) ou acione a apuração oficial via microsserviço Go + gRPC (POST /partidas/{id}/apurar).

Conecte a API Quarkus na porta 8080 para listar as partidas cadastradas no banco.

🔑 Entrar na Conta (JWT)

Autentique-se via POST /auth/login para receber seu token JWT e registrar palpites.

📝 Criar Nova Conta

Cadastre-se via POST /usuarios. Dica: e-mails iniciados com admin@ ganham perfil ADMIN automaticamente.

🎯 Meus Palpites

Espaço reservado para o módulo de histórico e edição de palpites do usuário (GET /palpites?usuarioId=...).

🏆 Ranking de Torcedores
